# MATLAB Mastery Path

A free, structured, module-wise MATLAB training program — entry level to master level, with runnable code in every module and a hands-on project at the end of each level. Focused on MATLAB's real-world niche: matrices, plotting, Simulink and numerical methods.

**Live site:** https://sigilipelli.github.io/matlab-mastery-path/

## Contents

- **Level 1 · Entry** — language foundations, matrices, plotting, basic numerical methods
- **Level 2 · Intermediate** — linear algebra, cell arrays/structs, vectorization, Simulink intro, curve fitting
- **Level 3 · Advanced** — OOP, advanced Simulink, signal processing, optimization, parallel computing, App Designer
- **Level 4 · Master** — model-based design, code generation, ML toolbox, GPU computing, CI/CD, capstone
